Friend's two-cipher puzzle — solved

"Cipher a friend made. It's made of 2 different ciphers … I think one of them is base64." — the guess was right, and the other cipher is a Caesar shift.

Source: r/Cipher “Cipher a friend made”, posted by u/Maleficent-Mango5262.

Ciphertext (52 characters)
FQrvSQXyIGviSQPtmw9jmiL0kQEqnQPslQEqm3BroGFuSQFdmRB5
Plaintext
The chair across the table stayed empty

Recovered by Caesar −10 (written as +16) on the letters, then Base64. Re-encoding the plaintext reproduces the ciphertext exactly.

How it was made (and undone)

PlaintextThe chair across the table stayed empty

1. Base64VGhlIGNoYWlyIGFjcm9zcyB0aGUgdGFibGUgc3RheWVkIGVtcHR5
→
2. Caesar +10 (letters only)FQrvSQXyIGviSQPtmw9jmiL0kQEqnQPslQEqm3BroGFuSQFdmRB5

To decode, run it backwards: shift every letter back 10 places (A–Z and a–z each wrap within their own case; digits unchanged), then Base64-decode the result. Equivalently, shift forward 16, which is how the brute-force below lists it.

About "two halves". The puzzle description suggested one half uses one cipher and the other half another. That isn't the structure: both ciphers apply to the whole string, stacked as layers (Base64 first, Caesar on top). I also tested every split point with a Caesar shift and Base64 on either side alone, and found nothing except the whole-string shift +16 (see solve.py). Half-and-half is how it looks when you don't yet know the layers are stacked: the first thing you see is a Base64-looking string that won't decode.

Only one shift gives printable ASCII. Chance of a random 39-byte decode being all printable ASCII is about (95/256)39 ≈ 1.6e-17, so this isn't a coincidence. The shifted text is also the textbook Base64 of English: VGhl = "The".

A tell you could have spotted

  • The ciphertext contains digits 9 0 3 5 but no +, / or =, and it's a multiple of 4 long (52). That fits Base64 with a letter-only substitution on top.
  • SQ occurs 3 times. In Base64, IG is what a space at the start of a 3-byte group looks like when followed by a letter from a–o. I→S and G→Q are both +10, so the shift can be read straight off that pair.
  • Digits stay put, so the substitution isn't a rotation of the whole 64-symbol Base64 alphabet. I tried that first (all 64 rotations, all split points) and it failed. It's ROT-style on letters only.
