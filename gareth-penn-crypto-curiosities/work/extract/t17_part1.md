# Methods

### M: Radian angle on the Bay Area map (Mt. Diablo apex)
- Category: map/geography
- Rules: Draw an angle of 57-58 deg (1 radian = 57.2957795131 deg = 57 deg 17' 44") on acetate; put apex on Mt. Diablo peak; rotate until one leg passes through the Blue Rock Springs murder site; the other leg then passes through Presidio Heights (Washington & Cherry, Stine murder). Prompt: Zodiac's "Mount Diablo Code concerns radians & # inches along the radians" and "four inches along the radian".
- Examples: Blue Rock Springs - Mt. Diablo - Presidio Heights = 1 radian (frontispiece map, PDF 5). Penn concludes Stine was chosen because "he needed a victim at a particular location"; site predetermined; the cab was moved from Washington & Maple to Washington & Cherry.
- Claims: murders are a geometric design visible only "from the perspective of outer space"; killer is mathematically sophisticated ("genius").
- Citation(s): T17 frontispiece (Part 1, PDF p.5); T17 pp.3-4 (Part 1, PDF pp.8-9); p.26 (PDF 31).

### M: WIZARD cipher (reverse alphabet with pair drop-out)
- Category: cipher (classical)
- Rules: A<->Z, B<->Y, C<->X ... (atbash). Difference from atbash: where a matching pair (letter + its mirror, e.g. GT, PK) occurs in a text, the pair drops out. Used almost always with anagram; WIZARD-pairs = superfluous material.
- Examples: WIZARD -> DRAZIW (all letters are pairs W/D, I/R, Z/A -> word vanishes); BEVY -> YVEB, GRIT -> TIRG. FV -> UE (WIZARD of the 340 group FV = Eugene's code UE).
- Claims: name chosen because "the word itself vanishes as if by magic".
- Citation(s): T17 p.14-15 (PDF 19-20); p.69 figure note (PDF 74).
