6. Interactive visualizer

Type in either box and the other one updates. Plaintext is encoded and ciphertext is decoded live, and each pair gets a card showing the run of letters it points into. The input can be any text: characters the cipher can't represent are flagged rather than silently dropped.

Options: spare codes and input handling

Spare codes are key-letter + digit pairs that no letter uses. In this puzzle V5 is the word space; the others are unexplained, so they are left unmapped by default. Mapping one to a punctuation mark lets you test a hypothesis, e.g. V6 = period.
