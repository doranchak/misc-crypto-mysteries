How it works
  • Every page is cut into cipher lines. Under each detected glyph there is a marker (blue triangle on the image edge, dashed guide line) and a letter box. Type the letter(s) for that glyph; the box fills blue. Letters are stored in upper case.
  • Typing flow: a letter advances to the next glyph (see “auto-advance”). Space marks a word break (blue bar) and, in an empty box, puts the break after the previous glyph. Backspace in an empty box steps back and clears the previous box (first removing a word break). ←→ / Enter / Shift+Enter move, ↑↓ jump to the previous / next line. Several letters in one glyph (TH, ING, AND…): click the box with the mouse, then type — clicking turns auto-advance off for that box.
  • Fix the segmentation: drag a blue triangle to move a marker; double-click the image to add a marker (glyph missed or merged); click the little × on a box (or Alt+Backspace, or right-click a triangle) to delete a spurious one. “Detected glyph boxes” shows what the segmenter found.
  • Spacing: boxes spread themselves apart so they never overlap (thin lines connect each box to its glyph). Use the line's gap slider for more or less room, switch spread off to place boxes straight under the glyphs, and use the global zoom for the whole page.
  • Saving: everything (letters, markers, word breaks, spacing, settings) is saved automatically in this browser's local storage and restored when you reopen this file. Because local storage is tied to the browser and file location, use export JSON now and then as a backup; import JSON restores it anywhere.
  • Add a box on a line: the + box button in a line's header lets you click once on the strip to add a marker there (same as double-clicking). Free letter boxes (the panel above the lines) work anywhere on the full page image, not only on the detected lines.
  • Ctrl/⌘+Z undoes the last change on the line (or the free boxes of the page) you were editing (the most recent edits first).
  • Safety: this version only adds data to what was already saved (free boxes live in a separate field); the first time it ran it also kept a copy of your earlier saved state in this browser (). If the stored data is ever in an unrecognised format the editor will not overwrite it.

Free letter boxes — add a box anywhere on the page
For anything the line strips do not cover (missed lines, headings, marginalia, a glyph the segmenter dropped): double-click the page image to drop a letter box at that spot (or press add box, then click once). Drag the red ring to move it; type the letter(s) in the box under it. Same keys as in the lines (Space word break, Backspace, Enter, arrows, Alt+Backspace or right-click the ring to delete). Boxes are listed in reading order (rows by height, then left to right).
