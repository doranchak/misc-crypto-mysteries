How the cipher works

  1. Split the text on whitespace into tokens. Punctuation stays attached to its word and counts toward the token's length.
  2. Key length: each token is shifted by the length of the previous token.
  3. Direction: even-numbered tokens (0, 2, 4, …) shift forward (+); odd-numbered tokens shift backward (−).
  4. First token: its "previous" token is the last token of the message (wrap-around). Both the post's example and the real message fit this rule; they cannot distinguish it from another rule that yields the same numbers.
  5. Only A–Z/a–z change; case, spacing and punctuation are preserved. Shifts preserve token length, so the decrypter reads key lengths straight off the ciphertext.

Worked example from the post: Hello secret agent → Mjqqt nzxmzo gmktz
